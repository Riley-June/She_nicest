# 轨迹 · UI 交互原型

这是一个移动端优先的可交互 HTML 原型，采用沉浸式蓝色背景、玻璃拟态卡片和时间线留存界面，用于验证产品主流程。

## 运行

直接用浏览器打开 `prototype/index.html` 即可。也可以在项目目录启动任意静态服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/prototype/`。

## 当前可体验流程

- 「此刻 / 留存」双 Tab 切换
- 输入文字并选择三种 AI 回应模式
- 保存一条回声，并在时间线查看历史
- 按日期或「找工作」标签查看留存
- 对留存内容进行编辑、加标签和删除
- 打开设置底部抽屉
- 切换左手 / 右手布局
- 切换三种低饱和度背景
- 开关主动提醒与历史回声授权
- 图片、音频和视频入口已预留
- 所有交互数据保存在浏览器本地，无需后端即可体验
- 页面背景使用 `trajectory-bg.mp4`，打开入口页面时会自动静音循环播放

## 设计约束

- 不包含社区、评论、排行榜、打卡和 KPI
- 不默认发送主动提醒
- 当前页面入口为 `prototype/index.html`，视觉和交互集中在单文件中，便于部署和预览
- 目前 AI 回复为本地占位逻辑，接入真实模型时保留 `responseFor()` 的输入输出边界
