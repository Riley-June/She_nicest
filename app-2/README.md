# 轨迹 · UI 交互原型

这是一个移动端优先的静态交互骨架，用于在视觉方案确定前验证产品主流程。

## 运行

直接用浏览器打开 `prototype/index.html` 即可。也可以在项目目录启动任意静态服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/prototype/`。

## 当前可体验流程

- 「此刻 / 故事」双 Tab 切换
- 输入文字并选择三种 AI 回应模式
- 保存一条回声，并在故事页查看历史
- 打开设置底部抽屉
- 切换左手 / 右手布局
- 切换三种低饱和度背景
- 开关主动提醒与历史回声授权
- 图片、音频、视频和标签入口已预留
- 浏览器 favicon、Apple Touch Icon 和 Web App manifest 已统一使用轨迹图标

## 设计约束

- 不包含社区、评论、排行榜、打卡和 KPI
- 不默认发送主动提醒
- 视觉层集中在 `styles.css`，便于替换为后续版面和外观方案
- 目前 AI 回复为本地占位逻辑，接入真实模型时保留 `responseFor()` 的输入输出边界
